# Notebook conventions

Use notebooks for exploration and visual analysis; move reusable code to `src/memn2n/` so training can run headlessly.

- `01_dataset_exploration.ipynb`: starter; currently demonstrates the offline fixture, no official dataset downloaded.
- `02_baseline.ipynb`: future.
- `03_attention_analysis.ipynb`: future.

Before committing a notebook, clear outputs, remove local file paths/secrets and keep cells reproducible.
